Panduan Pengguna OCRMe IDP

Selamat datang di OCRMe — Intelligent Document Processing. Platform AI ini merubah dokumen fisik/digital (Faktur, Nota, KTP, Rekening Koran, PDF, Office) menjadi data terstruktur secara instan & otomatis.

Gemini AI & LLM 100% Offline Fallback
Langkah Cepat Menjalankan Aplikasi
1. Python Local (Streamlit)

Jalankan aplikasi berbasis Python Streamlit secara lokal di komputer Anda:

streamlit run app.py
2. Docker Container

Jalankan tanpa install dependencies menggunakan Docker Compose:

docker-compose up -d --build
3. Vercel Web Studio

Deploy web studio ini secara instan ke Serverless Vercel Cloud:

vercel --prod
Panduan Fitur Utama Studio
1. Document Processor Unggah dokumen (PDF, Gambar, Word, Excel) ➡ Pilih OCR Engine (EasyOCR / Tesseract) & AI Model (Gemini, OpenAI, Claude, Ollama) ➡ Klik "Process" untuk ekstraksi JSON, Tabel CSV, & Teks Asli.
2. Database & Analytics Pantau total dokumen terproses, persentase akurasi, rasio auto-parsing AI, serta visualisasi grafik distribusi kategori dokumen.
3. Accuracy Evaluator Uji presisi ekstraksi dengan membandingkan hasil OCR terhadap teks asli Ground Truth untuk menghitung skor CER & WER.

Pertanyaan Umum (FAQ)
Apakah wajib API Key?

Tidak wajib. Tanpa API Key, sistem otomatis aktif dalam Mode Offline (Regex Fallback) secara gratis tanpa internet.

Format file apa yang didukung?

Mendukung PDF (digital & scan), Gambar (PNG, JPG, WEBP), dan Dokumen Office (Word .docx, Excel .xlsx).

Di mana data disimpan?

Semua hasil ekstraksi tersimpan di database lokal data/ocr_database.db dan dapat diunduh ke JSON / CSV / TXT.
