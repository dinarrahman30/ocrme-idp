How to Deploy to Vercel
  1. Install Vercel CLI pada komputer Anda: 
    npm install -g vercel
  2. Jalankan perintah deployment pada folder project ini: 
    vercel --prod
  3. Proyek OCRMe Web Anda langsung aktif secara instan dengan SSL HTTPS otomatis di Vercel!
REST API Endpoint Example 
// Example cURL Request to Vercel Serverless Endpoint
curl -X POST https://your-project.vercel.app/api/ocr \
  -H "Content-Type: application/json" \
  -d '{
    "engine": "easyocr",
    "parsing_mode": "auto"
  }'
